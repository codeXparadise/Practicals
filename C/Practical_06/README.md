## 🎯 Aim

To print the multiplication table of a given number from 1 to 10 using a for loop.

## 📌 Objective

Understand loop initialisation, condition and update by repeating one multiplication ten times.

## 🧠 Concept in simple words

The program reads a number n and uses a for loop with a counter i that runs from 1 to 10. In every pass it prints n x i. The for loop packs the start value, the stop condition and the increment into one line, which makes repetition easy to read.

![Concept diagram](screenshots/diagram_06.png)

## 🔑 Basic concepts used

| Concept | Meaning |
| :--- | :--- |
| `for loop` | for (start; condition; update) repeats a block of code. |
| `Loop counter` | The variable i that controls how many times the loop runs. |
| `n * i` | The repeated multiplication printed in each pass. |

## ▶️ How to use

Run and enter a number, e.g. 5; the table 5 x 1 ... 5 x 10 is printed.
