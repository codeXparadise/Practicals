## 📖 About this repository

This repository is a complete, self-documented set of lab practicals for the subject **Introduction to Programming with C and SQL** of the B.Sc. (Artificial Intelligence) programme. Every practical lives in its own folder and contains three things — the **source file**, a **screenshots** folder with the program's real output, and a **README** that explains the aim, the objective, the concept in simple words, the basic building blocks used and a short conclusion.

The C programs are written to compile cleanly in **Turbo C / Turbo C++** as well as in modern compilers such as **GCC**, and the SQL scripts run in **MySQL / MariaDB**.

## 👤 Author's note

I built this repository as a clean, honest record of my first-semester laboratory work. Instead of dumping raw files, each practical is organised so that a reader — a classmate, a junior or a teacher — can open any folder and immediately understand *what* the program does, *how* to run it and *what output* to expect. The aim is that the repository teaches, not just stores.

## 🚀 How to use

1. Open the **C** or **SQL** folder and pick a practical.

2. Read its `README.md` to understand the aim and the concept.

3. Compile/run the main file (instructions are inside each README).

4. Compare your output with the screenshot provided.


**C (GCC):** `gcc practical_XX.c -o practical_XX && ./practical_XX`  
**SQL (MySQL):** `SOURCE practical_X.sql;`
